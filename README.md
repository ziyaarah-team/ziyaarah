# 🕋 Ziyaarah – Your Spiritual Journey Companion

## 📖 Overview

Ziyaarah is a web application designed to help Muslims prepare for and manage their Hajj and Umrah journeys. The platform provides travel planning tools, ritual tracking, and spiritual resources to make the pilgrimage experience more organized and meaningful.

This project was developed as part of the **Gabi School Software Engineering Bootcamp**.

---

## 🎯 Project Goals

* Help pilgrims plan their Hajj or Umrah journey.
* Track important rituals and pilgrimage stages.
* Organize travel details and checklists.
* Provide spiritual guidance and resources.
* Create a simple and user-friendly experience.

---

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/ziyaarah-team/ziyaarah.git
```

Navigate to the project:

```bash
cd ziyaarah
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
