 # 🌙 Ziyaarah – Team Guide

## 1. What is Ziyaarah?

Ziyaarah is a web application that helps Muslims plan and manage their Hajj or Umrah journey.

The app helps users:
- Plan their trip
- Track rituals
- See upcoming steps
- Follow checklists
- Access useful learning resources

---

## 2. Our MVP

Our MVP includes:

### 🔐 Authentication
- Signup
- Login
- Logout

### ✈️ Trip Planner
- Create a trip
- View a trip
- Edit a trip
- Delete a trip

### 🕋 Ritual Tracker
- Track rituals
- Mark rituals as completed
- See completed and pending rituals

### 🏠 Dashboard
- Show journey progress
- Show completed rituals
- Show upcoming steps

---

## 3. Stretch Features

These are NOT our priority now:

- Memory Journal
- Group Planner
